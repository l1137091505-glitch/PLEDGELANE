# PLEDGELANE page plan

software

Deal: collage hero; palette `cool-grey-cobalt` because a cool paper-like ground makes public funding records legible while cobalt separates actions from evidence; Geist + Geist Mono; sharp radius; `nav-cards`, `footer-columns`, `close-word`, `surface-pairs`, `solid`, `wordmark`; dealt moments `letters-assemble` and `iris-opens`, interpreted as the large proof statement and the binary settlement panel without scroll-hiding copy.

- Hero — one all-or-nothing promise, live campaign UI collage, 1 screen.
- Campaign ledger — every campaign, deadline, funding and status in ruled rows, 1–2 screens.
- Settlement rules — publish, contribute, claim or refund shown as a bifurcated path, 1 screen.
- Network proof — type-led public/private/settlement statement plus contract facts, 1 screen.

Primary action: Start a campaign.

Voice card: Exact, public and calm; short sentences; “lane” is used only as the product’s own organizing metaphor.
